# StudySync – Smart Student Academic Planner

A full-stack web application that helps university students manage assignments,
examinations, timetables, study sessions, deadlines and GPA in one place.

> Status: under development. Full documentation will be added before the v1.0.0 release.

## Tech Stack

Node.js (v22.13 or newer), Express, SQLite (Node's built-in `node:sqlite`),
HTML5, CSS3, JavaScript (ES6+), Bootstrap 5, Chart.js, FullCalendar.

## Getting Started

```bash
npm install
cp .env.example .env   # then edit .env with your own values
npm run dev
```
